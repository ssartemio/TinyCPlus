# API reference

```c
void* malloc(u64 size);
```

## calloc

```c
void* calloc(u64 count, u64 size);
```

## realloc

```c
void* realloc(void* pointer, u64 size);
```

## free

```c
void free(void* pointer);
```

## exit

```c
void exit(i32 code);
```
