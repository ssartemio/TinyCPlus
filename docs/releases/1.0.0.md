# TinyC+ 1.0.0

Primera versión estable del compilador nativo TinyC+, con frontend C11, generación
de C inspeccionable y backends libtcc/TinyCC o compilador C externo. Esta entrega
cierra el alcance 1.0 sin incorporar la GUI gráfica experimental.

## Funcionalidad incluida

- Tipos, clases, interfaces, genéricos, closures, streams y FFI C, con memoria manual.
- Librería estándar, threads, Task/Future, Channel y async/await.
- TCP/UDP/DNS, Protobuf proto3 y gRPC unary sobre HTTP/2 sin cifrado (h2c).
- TUI, editor TinyEdit, formateador, documentación, pruebas y REPL.
- Bootstrap de dependencias desde fuentes incluidas, documentación y ejemplos.

## Instalación y cambios de entrega

Descargue los archivos y `SHA256SUMS.txt` de
[GitHub Releases](https://github.com/ssartemio/TinyCPlus/releases). Se publican:

| Sistema destino | Paquete |
|---|---|
| Windows x64 | Instalador `.exe` por usuario |
| Ubuntu 24.04 amd64 | Paquete `.deb` |
| Fedora 42 x86_64 | Paquete `.rpm` |
| Otros sistemas | Archivo de fuentes para compilar en el destino |

La consola del menú Inicio de Windows empieza en la carpeta instalada y habilita
`tiny`, `tinyc` y `tinyedit`, incluso sin modificar el PATH del usuario. También
se cubre el caso de crear un programa propio fuera de la instalación y generar
un ejecutable, incluidas rutas con espacios y archivos UTF-8.

Los paquetes Linux declaran las dependencias de desarrollo de libc necesarias
para compilar y ejecutar programas. El paquete Debian expresa además las
dependencias ABI de los binarios; compartir el formato `.deb` no garantiza
compatibilidad con distribuciones más antiguas. Ubuntu ARM64 y macOS ARM64 se
prueban desde fuentes y no reciben instaladores nativos en esta versión.

Para empezar en Windows, abra **TinyC+ console** y ejecute
`tiny run examples\hello.tc`: el ejemplo incluido imprime `30`. La
[guía de instalación](https://github.com/ssartemio/TinyCPlus/blob/v1.0.0/docs/INSTALLERS.md#crear-su-primer-programa) muestra cómo
crear un archivo nuevo que imprima `Hola mundo`, guardarlo y compilarlo.

## Requisitos y límites

El compilador instalado no requiere Python. Las herramientas de construcción,
pruebas y generación Protobuf sí lo utilizan. Linux necesita los archivos de
desarrollo C que instala el gestor de paquetes; compilar desde fuentes requiere
un compilador C, `make`, `sh` en POSIX y el SDK del sistema. TinyEdit necesita
una terminal con soporte ANSI.

La memoria sigue siendo manual, sin GC, ARC ni borrow checker. No se garantiza
ABI de 32 bits ni compilación cruzada. gRPC no incluye TLS, autenticación,
compresión ni streaming. La TUI aproxima la anchura Unicode y TinyEdit no incluye
undo/redo, resaltado de sintaxis ni múltiples documentos. Consulte los
[límites completos](https://github.com/ssartemio/TinyCPlus/blob/v1.0.0/docs/STATUS.md#límites-que-forman-parte-de-esta-versión).

Los instaladores se distribuyen sin firma Authenticode/GPG. Las sumas SHA-256
comprueban la integridad de los archivos descargados y no sustituyen una firma.
